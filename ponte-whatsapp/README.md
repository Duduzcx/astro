# Ponte do WhatsApp pessoal

Liga o seu número pelo QR code, como o WhatsApp Web, e conversa com o painel
do site. Sem Meta, sem Docker, sem banco.

```
npm install
copy .env.exemplo .env   (e preencha PONTE_CHAVE com a mesma chave de EVOLUTION_API_KEY na Vercel)
npm start
```

O passo a passo, o que o robô faz e o que ele nunca faz: `docs/prospeccao-whatsapp.md`.
